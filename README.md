# 三國志英傑傳 原生執行器（eiketsu-rt）

在現代的 Windows 上直接玩 DOS 版《三國志英傑傳》（中文版），**不需要 DOSBox**，而且多了這些方便的功能：

- ⚔️ **戰場上隨時存檔、讀檔**：功能選單多了「存檔」「讀檔」，打到一半也能存，失手了馬上讀回來。
- 💾 **存檔從 5 格變成 10 格**，清單直接寫著「汜水關之戰 第3回合」，一眼就知道是哪一場、第幾回合。
- 🔁 **第 10 格自動存檔**：每次我方回合結束都自動存一次，不怕忘記存。
- 🎵 原版的音樂、劇情、戰鬥、中文字型全部照原樣，跑的就是原版程式。
- 🖥️ 視窗可以自由縮放、縮小。

> 本專案**不包含遊戲本體**。你需要自備《三國志英傑傳》DOS 中文版的遊戲檔案。

---

## 準備

1. **遊戲檔案**：《三國志英傑傳》DOS 中文版，資料夾裡要有 `REKO3.COM`、`MAIN.EXE` 等檔案。
2. **Windows 10 / 11**（macOS、Linux 請看下面的「從原始碼執行」）。

## 安裝與開始遊戲（Windows，最簡單）

1. 到本頁右側的 **[Releases](../../releases)** 下載 `eiketsu-rt.exe`。
2. 把 `eiketsu-rt.exe` 放進**遊戲資料夾**（有 `REKO3.COM` 的那一層）。
3. 雙擊 `eiketsu-rt.exe`，開始遊戲！

```
三國志英傑傳\
├─ REKO3.COM
├─ MAIN.EXE
├─ ……（其他遊戲檔案）
└─ eiketsu-rt.exe   ← 放這裡，雙擊
```

> Windows 可能跳出「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」即可（因為執行檔沒有付費簽章）。

## 開始玩之前要知道的事

- **開頭的「請輸入正確密碼」**：這是原版查手冊的防拷畫面。**隨便輸入一個字再按 Enter** 就能進入。
- **操作**：跟原版一樣，用滑鼠。左鍵選擇、右鍵取消／關閉視窗。
- **聲音**：預設開啟；如果電腦沒有喇叭也能正常玩。

## 存檔說明

| 在哪裡 | 怎麼存 | 怎麼讀 |
|---|---|---|
| **戰場上** | 功能 → **存檔** → 選格子 → 是 | 功能 → **讀檔** → 選格子 → 是 |
| **戰場外**（城裡、大廳） | 遊戲問「現在儲存嗎？」時選「是」 | 標題畫面 → 讀取存檔 |
| **第 10 格** | 每次我方回合結束**自動存** | 跟其他格一樣讀 |

- 讀取戰場上的存檔，會回到你存的那一刻。大廳存的檔，在戰場上也能直接讀回大廳。
- 選「遊戲結束」、全軍撤退或勝負揭曉時，不會蓋掉第 10 格的自動存檔。
- 存檔放在遊戲資料夾裡（`MSAVE*.R3S`、`ESAVE*.R3S`，以及 `savestates\` 資料夾）。**想備份就整個複製起來**。
  `savestates\` 是「回到存檔那一刻」用的，別刪掉它。

## 常見問題

**Q：戰場上點「功能」，跑出全軍的移動範圍，不是選單？**
A：這是原版就有的行為（剛做完選單裡的動作後會這樣）。按右鍵取消，再點一次「功能」就好。

**Q：在戰場上讀某一格，出現「這個進度請在標題畫面讀取」？**
A：那是用原版方式存的舊檔（例如遊戲原本附的第 1 格，或用其他模擬器存的檔）。請回到標題畫面「讀取存檔」讀它；
之後再存一次，就能在戰場上直接讀了。

**Q：存檔清單上的日期都是 93/08/01？**
A：正常。執行器的時鐘固定從 1993 年那天開始算（為了讓問題能精確重現），請看格子上的名稱和回合數來分辨。

**Q：可以用原本 DOSBox 玩的存檔嗎？**
A：可以，存檔格式跟原版一樣。只是這類舊檔在戰場上不能直接讀，要從標題畫面讀（見上一題）。

**Q：遊戲當掉或畫面怪怪的？**
A：每次遊玩都會在遊戲資料夾的 `journal\` 留下操作紀錄。關掉視窗後，把最新的那個 `session-…txt` 附在
[Issues](../../issues) 裡回報，開發者可以一模一樣地重現你遇到的狀況。

## 從原始碼執行（macOS / Linux / 想自己編譯）

1. 安裝 Rust：<https://rustup.rs>
2. 把這個專案下載（或 `git clone`）到**遊戲資料夾裡面**：

   ```
   cd 你的遊戲資料夾
   git clone https://github.com/fanntone/eiketsu-rt.git
   ```

3. Windows 雙擊 `eiketsu-rt\play.bat`；macOS / Linux 執行 `eiketsu-rt/play.command`。第一次會先編譯，要等一下。

想了解原理、改程式或跑測試，請看 [DEVELOPMENT.md](DEVELOPMENT.md)。
